# Privacy Policy

Effective date: November 24, 2026

## 1. Application overview

REELVYRO Backup is a private administrative
application designed to provide secure database
backup and disaster recovery for REELVYRO.

## 2. Google user data accessed

The application uses the Google Drive API
with the limited drive.file OAuth scope.

The application accesses backup files and
folders that it creates or is explicitly
authorized to access.

It does not request unrestricted access
to the user's Google Drive, Gmail, contacts,
photos, or browsing history.

## 3. Use of Google user data

Google Drive access is used exclusively to:

- Upload encrypted database backups.
- Retrieve backup files for verification.
- Verify backup integrity.
- Support database recovery.
- Manage backup retention when configured.

Google user data is not used for advertising,
profiling, or training artificial intelligence
or machine learning models.

## 4. Data storage and protection

Database backups are encrypted using AES-256
before being uploaded to Google Drive.

Encryption keys are stored separately from
uploaded backup files.

OAuth credentials are stored in protected
server-side configuration files.

Access is restricted to authorized
REELVYRO administrators.

## 5. Data sharing

REELVYRO Backup does not sell Google user data.

Google user data is not shared with third
parties for advertising or marketing.

Google Drive is used as the authorized
backup storage provider.

Disclosure may occur where required by law.

## 6. Data retention and deletion

Backup files are retained according to
the configured backup retention policy.

The authorized administrator can manage
and delete backup files from Google Drive.

Google Drive access can be revoked through
the Google Account permissions settings.

Revoking access does not automatically
delete previously uploaded backup files.

## 7. Google API compliance

REELVYRO Backup's use and transfer of
information received from Google APIs
will adhere to the Google API Services
User Data Policy, including the
Limited Use requirements.

https://developers.google.com/terms/api-services-user-data-policy

## 8. Changes to this policy

This Privacy Policy may be updated to reflect
changes in application functionality,
security practices, or legal requirements.

## 9. Contact

For questions regarding this Privacy Policy,
contact the REELVYRO Backup administrator
through the support email displayed on
the Google OAuth consent screen.
